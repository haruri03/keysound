# keysound

[English](README.md) · **简体中文**

Windows 平台的键盘音效程序。每次按键都能发出声音——可以选内置音效模式，也可以加载自己做的音效包。

## 快速开始

1. 让 `keysound.exe` 和 `sounds` 文件夹留在同一个目录里。
2. 双击 `keysound.exe`。
3. 会出现一个小窗口，同时托盘里出现图标。右键托盘图标即可选择音效模式和各项开关。
4. 随便打几个字，就能听到声音了。

关闭窗口不会退出程序，它会留在托盘里；要真正结束请用菜单里的**退出**。

## 音效包

在 `sounds\` 下放一个文件夹，里面写上 `index.json` 和音频子目录，下次启动就会出现在 **Sound packs** 菜单里。完整教程——目录结构、`index.json` 每个字段、三种播放模式、体积上限和排错——见[音效包教程](docs/sound-packs_cn.md)。

## 设置

音效模式、当前音效包和两个开关会自动保存在程序旁边的 `keysound-settings.dat` 里。删掉这个文件即可恢复默认。

## 运行要求

Windows 10 或 11，64 位。如果程序打不开，先运行随附的 `Visual_C  RuntimePack_3.0.22.0317.exe` 安装运行库。

## 常见问题

- **托盘里没有图标**——窗口会显示托盘状态并每隔几秒自动重试；也可以直接用窗口上的按钮代替托盘操作。
- **没有声音**——检查系统音量合成器里本程序的音量，并看窗口状态行：它会显示已加载的音效数量和播放是否被受理。
- **在管理员权限的程序里没声音**——Windows 不跨权限等级传递输入，请把本程序也用管理员身份启动。
- **按住一个键会连续响**——不应该如此：一次物理按下只响一次。若出现请当作缺陷反馈。
