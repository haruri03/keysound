# 自定义音效包教程

[English](sound-packs.md) · **简体中文**

本页讲怎么从零做一个音效包，以及 `index.json` 每个字段到底怎么起作用。
程序本身怎么安装使用见 [README](../readme_cn.md)。

## 一、音效包放在哪里

音效包统一放在程序目录下的 `sounds\` 里，一个子目录就是一个音效包：

```
keysound.exe
sounds\
  我的音效包\
    index.json
    sounds\
      a1.wav
      a2.wav
```

启动后程序扫描 `sounds\` 下的每个子目录，凡是有可读 `index.json` 的都会出现在
**Sound packs** 子菜单里。没有 `index.json` 的目录不会被列出。

改完音效包不需要重新安装程序，也不需要改程序里的任何东西；菜单里重新选一次即可。
新增或删除目录后重启程序就能看到变化（程序只在启动和切换音效包时扫描）。

## 二、写 index.json

`index.json` 必须是 **UTF-8** 编码。最小可用的内容只有两个字段：

```json
{
  "name": "我的音效包",
  "mode": "assign"
}
```

完整示例（把每个键映射到一个音频文件，并额外准备一组随机音效）：

```json
{
  "name": "打字机",
  "mode": "assign",
  "repeat_sound": "",
  "assigned_sounds": [
    { "key": "1", "sound": "打字声 01.mp3" },
    { "key": "2", "sound": "打字声 02.mp3" },
    { "key": "A", "sound": "打字声 03.mp3" }
  ],
  "soundsList": ["打字声 01.mp3", "打字声 02.mp3", "打字声 03.mp3"]
}
```

字段说明：

| 字段 | 类型 | 必填 | 作用 |
|---|---|---|---|
| `name` | 字符串 | 是 | 菜单里显示的名字。缺这个字段整个包会被拒绝。 |
| `mode` | 字符串 | 是 | 播放方式为 `assign`、`repeat`、`random` 或 `mixed`；也接受中文别名 `指定`、`重复`、`随机`、`混合`。缺这个字段整个包会被拒绝。 |
| `assigned_sounds` | 数组 | 否 | 每个按键对应一个文件，元素形如 `{ "key": "...", "sound": "..." }`。 |
| `soundsList` | 字符串数组 | 否 | 备选音效文件列表，`random` 模式从这里抽。 |
| `repeat_sound` | 字符串 | 否 | `repeat` 模式下键盘按下时播放的单个文件；留空则没有重复音效。 |

`key` 支持普通字符（`1`、`A`）和功能键名（例如 `L Shift`、`R Ctrl`、方向键）。
写不准可以在程序里先选「键名模式」，按一下想用的键，看窗口提示的名字。

`sound` 只写**文件名**，不要写路径，也不要带 `sounds\` 前缀——程序会自动到
包目录下的 `sounds\` 子目录里找，找不到时再查找包目录本身：

```
<包目录>\sounds\<sound 里写的文件名>
```

文件名里可以有空格和中文，例如 `打字声 03.mp3`。

## 三、四种模式的区别

- **`mixed`（`混合`）**：键盘上有指定映射时优先播放指定文件；未指定的键从 `soundsList` 随机抽取，列表为空则静音。启用鼠标音效后，鼠标松开仅播放 `Mouse Left`、`Mouse Right`、`Mouse Middle` 的指定映射，不使用随机池。
- 音频文件先从包目录的 `sounds` 子目录查找，再从包目录本身查找；文件名不能包含目录分隔符。

- **`assign`（`指定`）**：按 `assigned_sounds` 精确匹配。按下的键没有对应条目就不出声。
  适合「每个键一个独特声音」的包。
- **`random`（`随机`）**：从 `soundsList` 里随机抽一个播放，不管按的是哪个键。
  适合「随便敲都有声音但每次不同」的包。
- **`repeat`（`重复`）**：键盘按下时播放 `repeat_sound`；这个字段为空则没有可播放的重复音效。

键名列表用 `assign`，全体按键用 `random`，只想要一个长音效用 `repeat`——按需要挑一个即可。

## 四、音频文件的要求与上限

- 支持 `.wav` 和 `.mp3`，其他扩展名不会被加载。
- 选包后程序会把所有音频**一次性解码进内存**再开始播放，所以切包后要等窗口
  状态行显示「内存音效就绪」（英文界面 `Memory sounds ready`）才开始响应按键。
- 单个文件上限 16 MiB，整包保留音频上限 128 MiB。超过上限的文件会被跳过，
  窗口状态行会给出错误码（`HRESULT`）。
- 解码失败的包不会退回到磁盘播放：确认格式没坏、文件没被别的程序占用，
  然后重新选一次包。

## 五、试听与排错

1. 选包 → 看窗口状态行：显示「内存音效就绪」且文件数、占用内存正常，说明加载成功。
2. 按几个键 → 状态行的「提交」计数应当增加；数字不涨说明按键没有走到音效包。
3. 有计数但没声音 → 检查系统音量、输出设备，以及音量合成器里本程序的音量。
4. 在管理员权限的程序里没声音 → Windows 不允许低权限程序把输入送进高权限窗口，
   把本程序也用管理员身份启动。
5. 整套目录搬走后不响 → 音效包路径是相对于程序目录的，`sounds\` 必须跟着 `keysound.exe` 一起搬。

## 六、最小可用的自检清单

- [ ] 目录在 `sounds\` 下，且目录名和 `name` 可以不同
- [ ] `index.json` 是 UTF-8，`name` 和 `mode` 都在
- [ ] `mode` 是 `assign`／`random`／`repeat`／`mixed` 之一（或 `指定`／`随机`／`重复`／`混合`）
- [ ] 每个 `sound` 只是文件名，对应文件位于 `<包目录>\sounds\` 或 `<包目录>\` 本身
- [ ] 文件是 `.wav` 或 `.mp3`，单个不超过 16 MiB，整包不超过 128 MiB
- [ ] 重启程序后菜单里能看到这个包名

全部满足还是没声音，看窗口状态行的错误码，再对照上面的排错步骤。
